
# Componentes UI básicos con HTML y CSS

Proyecto frontend que reúne ejemplos simples de componentes de interfaz de usuario construidos solo con **HTML** y **CSS**. Incluye botones, barra de navegación, alertas de estado y una tarjeta de perfil tipo “card”.

## Demo

- Vista local en el navegador usando `index.html`.
- La página muestra una barra de navegación superior, botones con distintos estilos, alertas de colores y una tarjeta de perfil centrada.

## Características

- Barra de navegación horizontal con enlaces de ejemplo.
- Botones de colores con estados hover.
- Alertas de:
  - Información (primaria).
  - Éxito.
  - Peligro.
- Tarjeta de perfil con imagen, nombre y descripción breve.

## Tecnologías utilizadas

- HTML5 para la estructura del documento.
- CSS3 para estilos, colores, sombras y efectos hover.
- Iconos a través de una librería como bootstrap-icons

## Instalación y uso

1. Clona o descarga este repositorio.
2. Abre el archivo `index.html` en tu navegador.
3. Modifica los estilos en `styles.css` (o el archivo CSS que uses) para adaptar colores, tamaños y tipografías a tus necesidades.

## Estructura de archivos

- `index.html`: Contiene la estructura de la página y los componentes.
- `styles.css`: Define los estilos para la barra de navegación, botones, alertas y tarjeta de perfil.

## Personalización

- Cambia textos de los botones y alertas para adaptarlos a tu proyecto.
- Sustituye la imagen y el texto de la tarjeta de perfil por tus propios datos.
- Ajusta colores, bordes y sombras para integrarlos con el diseño de tu sitio principal.
